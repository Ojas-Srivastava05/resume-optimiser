## Confirmed process pattern (merge senior + GFG + repo intel)

| Round | What happens | Prep priority |
|-------|----------------|---------------|
| **1. OA** | 2 DSA + ~20 CS MCQs (OS, DBMS, CN, OOP) | Striver Easy–Medium + GFG CS DB |
| **2. HireVue** | ~5 recorded Qs, 30–60s think, 3 attempts each | Script intro, why GE, strengths |
| **3. Technical** | 30–75 min; **panel-dependent** | Projects + DSA logic + OOP + CS fundamentals |
| **4. HR** | ~15 min; hobbies, clubs, teamwork | STAR stories, GE products |
| **5. Personality** | 100 situational Qs + 3 timed puzzle games | Stay consistent; games = simple puzzles |

**Senior rule:** Mostly **logic**, not live hardcoding — but **panel varies**. Prepare both.
