4. CS flash — one-liners

OOP

  • 4 pillars: encapsulate, inherit, polymorph, abstract
  • Overload = compile-time; override = runtime
  • Virtual/override for runtime polymorphism
  • May ask: implement polymorphism live

OS

  • Process vs thread; mutex vs semaphore
  • Deadlock: 4 conditions; race → locks
  • Paging / virtual memory basics

DBMS / SQL

  • ACID; 1NF–3NF; PK/FK; index tradeoff
  • INNER vs LEFT JOIN
  • 3rd highest salary: ORDER BY … LIMIT 1 OFFSET 2

CN / System

  • OSI 7 layers; TCP vs UDP; 3-way handshake
  • DNS, DHCP; REST + JSON
  • 3-tier: UI → business → data
