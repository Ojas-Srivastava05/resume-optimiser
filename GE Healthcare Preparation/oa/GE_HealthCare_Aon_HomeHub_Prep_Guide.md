# 1. Full Test Format Overview

## 1.1 Platform

| Item | Detail |
|---|---|
| Portal | Aon **HomeHub** — `aon-assessment.com/homehub` |
| Access | Personal invitation link + candidate ID by email |
| Total duration | **~50 minutes** (including instructions) |
| Device | Laptop/desktop strongly preferred |
| Browser | Chrome / Edge / Firefox; **pop-up blocker OFF** |
| Deadline | Typically **3 days** from invitation |

## 1.2 The four parts

| # | Module | Product name | Time | Items | Scored how |
|---|---|---|---|---|---|
| A | Personality | **ADEPT-15** | 25–30 min | Adaptive forced-choice pairs | Trait profile — no right/wrong |
| B | Inductive reasoning | **scales ix** (sometimes clx) | **5 min** (ix) | 20 tasks — odd one out of 9 | Correct under time |
| C | Deductive reasoning | **gapChallenge** | **6 min** | Unlimited — as many as you can | Correct under time |
| D | Complex planning | **motionChallenge** | **6 min** | Unlimited puzzles | Solved under time |

**Order:** personality usually first (longest). Cognitive modules are short and back-to-back. Total elapsed time commonly **45–55 minutes**.

## 1.3 Module detail

### A. ADEPT-15 (~25–30 min)

- Forced choice: two workplace statements → pick which is *more like you*
- Adaptive: next pairs depend on prior answers
- Measures **15 traits** in **6 styles**
- No right/wrong — but **consistency** matters
- Traits include: Adaptability, Ambition, Assertiveness, Awareness, Composure, Conceptual, Cooperativeness, Drive, Flexibility, Humility, Liveliness, Mastery, Positivity, Sensitivity, Structure

### B. Inductive — scales ix (5 min)

- Nine objects (A–I); eight follow one rule; **one does not**
- Rules: counts, sides, fill, orientation, symmetry, nesting, numbers
- Pace: **~15 seconds per task**

### C. Deductive — gapChallenge (6 min)

- 4×4 or 5×5 grid; one cell is `?`
- Rule: each symbol appears **once per row and once per column** (Latin square)
- Unlimited questions; difficulty rises

### D. Planning — motionChallenge (6 min)

- Ball + deflectors/blockers + exit
- Reposition deflectors so the ball reaches the exit
- Efficiency (few moves) + volume both matter

**Text model used in this guide:**

- Grid 6×6, columns A–F, rows 1–6
- `\` deflector: East→South, South→East, West→North, North→West
- `/` deflector: East→North, North→East, West→South, South→West
- `#` blocker stops the ball; wall stops the ball
- One "move" = relocate one deflector

## 1.4 Critical platform rules

| Rule | Consequence |
|---|---|
| No mid-task exit | Closing mid-module usually forfeits that module |
| 20-min idle logout | Between modules only — keep breaks short |
| 3-day deadline | Finish ≥24h before expiry |
| Pop-ups allowed | Blocked pop-up looks like a freeze |
| Quiet room | Notifications can cost several timed items |
| Technical failure | Screenshot + email support same day |

# 2. Sample Questions

## 2.1 ADEPT-15 — 8 sample pairs

Choose the statement **more like you at work**. Trait tags are for learning only (not shown live).

| # | Statement A | Statement B |
|---|---|---|
| 1 | I keep a detailed written plan for every project. *(Structure)* | I adjust my approach as soon as new information arrives. *(Flexibility)* |
| 2 | I speak up early when I disagree with a decision. *(Assertiveness)* | I make sure everyone has had their say before I add mine. *(Cooperativeness)* |
| 3 | I stay calm when a deadline slips. *(Composure)* | I push hard to recover the lost time. *(Drive)* |
| 4 | I enjoy debating abstract ideas and models. *(Conceptual)* | I prefer to test an idea in practice straight away. *(Mastery)* |
| 5 | I notice quickly when a colleague is frustrated. *(Sensitivity)* | I stay focused on the task until it is complete. *(Drive)* |
| 6 | I credit the team before I mention my own part. *(Humility)* | I make sure my contribution is visible to decision-makers. *(Ambition)* |
| 7 | I bring energy and talk freely in meetings. *(Liveliness)* | I read my own reactions accurately under pressure. *(Awareness)* |
| 8 | I keep a positive outlook when a plan fails. *(Positivity)* | I re-forecast realistically as soon as a plan fails. *(Conceptual)* |

**No answer key.** Answer from one stable **work** self. Inconsistency across similar pairs lowers profile confidence.

## 2.2 Inductive — 6 samples (scales ix style)

**S-I1.** Polygon + dots: A △3 · B □4 · C ⬠5 · D ⬡6 · E □4 · F △3 · G ⬠5 · H ⬡**5** · I △3

**S-I3.** Digits sum to 9: A 63 · B 27 · C 90 · D 45 · E **84** · F 18 · G 72 · H 36 · I 54  
**S-I4.** Square sits on arrow side: A↑↑ · B→→ · C↓↓ · D←← · E↑↑ · F→→ · G↓**↑** · H←← · I↓↓  
**S-I5.** Vertical symmetry: A H · B **R** · C M · D T · E U · F V · G W · H A · I Y  
**S-I6.** Black = white + 1: A 3B2W · B 4B3W · C 2B1W · D 5B4W · E 3B2W · F 6B5W · G 4B3W · H 2B1W · I **4B4W**

## 2.3 gapChallenge — 5 samples

**Legend:** `O` circle · `#` square · `^` triangle · `*` star · `+` cross · `.` empty · `?` solve  
**Rule:** each symbol once per row and once per column.

**G-S1**

```
O # ^ *
# O * ^
^ * O #
* ^ # ?
```

**G-S2**

```
O # ^ *
# ^ ? O
^ * O #
. O # ^
```

**G-S3**

```
O # ^ *
^ * O #
* O # ^
# ? * .
```

**G-S4 (5×5)**

```
O . ^ * +
# O * + ^
^ + O # ?
* ^ . O #
+ * # ^ O
```

**G-S5 (5×5)**

```
O # ^ . +
^ * + O #
. O # ? *
# ^ * + O
* + O # ^
```

### Sample gap answers

| Grid | Ans | Why |
|---|---|---|
| G-S1 | **O** | Col4 missing only O |
| G-S2 | **\*** | Col3 missing only * |
| G-S3 | **^** | Col2 missing only ^ |
| G-S4 | **\*** | Col5 missing only * |
| G-S5 | **^** | Row∩Col missing-sets = ^ |

**Technique:** scan **column first, then row**. If incomplete, intersect missing-symbol sets.

## 2.4 motionChallenge — 3 samples

**M-S1** Ball A1 East → Exit F6. Fixed `\` at C1; movable `\` at E4. Blockers D2, B5.  
**Ans:** 1 move — place `\` at **C6**. Path: A1→C1↘C6→F6 EXIT.

**M-S2** Ball A1 East → Exit A6. Movable `\` C2, `/` B5. Blockers B4,C4,D5,F3.  
**Ans:** 2 moves — `\`→**E1**, `/`→**E6**. Path: A1→E1↘E6←A6 EXIT.

**M-S3** Ball C1 South → Exit F1. Movable `\` B3, `/` A6. Blockers D2,E3,D4,E6.  
**Ans:** 2 moves — `\`→**C5**, `/`→**F5**. Path: C1→C5→F5↑F1 EXIT.

# 6. Day-of Checklist & Strategy

## Before (24h)

- [ ] Re-do official demos for gapChallenge, scales ix, motionChallenge (~15 min)
- [ ] Memorise `\` and `/` deflection rules
- [ ] Sleep > cramming
- [ ] Confirm HomeHub login works (**do not start a module**)
- [ ] Block a 60-minute window

## Technical (30 min before)

- [ ] Laptop plugged in
- [ ] Strong Wi-Fi / ethernet
- [ ] Chrome/Edge; pop-ups allowed for `aon-assessment.com`
- [ ] VPN, ad-blockers, Slack/Teams/mail closed
- [ ] Notifications off; phone in another room
- [ ] External mouse if available
- [ ] Paper + pen ready

## Strategy

**ADEPT-15:** Steady pace; one work context; both options sound good — pick what's *more true*, not more impressive.

**Inductive:** Fixed scan — count → sides → fill → orientation → position. Cap ~20s; guess and move on.

**gapChallenge:** Column → row → intersect missing sets. Don't solve the whole grid. ~20s/item target.

**motionChallenge:** Plan **backwards from exit**. Blockers reveal the intended corridor. Trace fully before placing. Cap ~60s then take next puzzle.

## Between modules

Breaks OK **between** modules only. Keep under 10 min (20-min idle logout). Don't ruminate on finished modules.

## If something breaks

1. Don't close unless clearly crashed  
2. Screenshot (URL + clock)  
3. Check pop-up blocker first  
4. Email **indiasupport@aon.com** same day + notify recruiter  
5. Don't restart the whole battery blindly

## Final pre-flight

- [ ] Pop-ups allowed  
- [ ] VPN/extensions off  
- [ ] Phone away  
- [ ] Charger in  
- [ ] Paper ready  
- [ ] 60 min free  
- [ ] Deflection rules fresh  
- [ ] gapChallenge scan order fresh  

**Good luck.**
