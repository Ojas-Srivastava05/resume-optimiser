\section{1. Corrected verdict (30 min)}
\begin{itemize}
  \item Your invite duration (\textbf{30 minutes}) does \textbf{not} match the long historical GE OAs (often 60--120 min with aptitude + MCQs + 2 coding).
  \item On CoCubes, companies enable \textbf{only the modules they want}. A 30-minute slot almost always means \textbf{one module} (or one custom short block), not the full six-module employability battery.
  \item The only CoCubes module whose \textbf{standard} duration is exactly \textbf{$\sim$30 minutes} at the low end is the \textbf{Coding} module (usually listed as 30--45 min). Aptitude is usually 45 min; Computer Fundamentals is usually 15 min --- companies can still shorten/customize.
  \item So for a GE + CoCubes + \textbf{30 min} invite, the \textbf{most likely} formats are below --- \textbf{read the invite / first screen} to see which one you got.
\end{itemize}

\section{3. What does \emph{not} fit a 30-minute total}
Do \textbf{not} prep as if you will get the old long GE packs in one sitting:
\begin{itemize}
  \item GFG Off-Campus 2021 (Cocubes-named): aptitude + tech MCQs + \textbf{2 coding}, sectional cutoffs --- that is a \textbf{multi-section} session, typically much longer than 30 min.
  \item SVNIT senior EID intel: \textbf{2 DSA + 20 CS MCQs} --- realistic for $\sim$45--90+ min, \textbf{tight/unlikely} as a full 30-min package unless coding is tiny.
  \item PCON EID 2024: \textbf{90 min} (reasoning + CS MCQ + 2 Med--Hard coding).
  \item GFG SVNIT SDE Intern: $\sim$\textbf{2 hours}.
  \item EEDP FTE GFG: 50 MCQ / 50 min + 2 coding / 45 min.
\end{itemize}
Those remain useful for \textbf{content} (what GE likes to ask), but they are \textbf{not} the format of a 30-minute invite.

\section{5. GE content still useful (even if format is short)}
If your 30-min slot is \textbf{coding-heavy}, practice Easy--Medium:
\begin{itemize}
  \item Arrays / hashing (Two Sum), strings, prefix sums
  \item Linked list reverse / basics
  \item Trees BFS / leaf-sum style
  \item Easy DP (climbing stairs)
\end{itemize}
If it is \textbf{MCQ-heavy}, prioritize:
\begin{itemize}
  \item Aptitude speed (percentages, ratios, series, DI, grammar)
  \item CS flash: OOP pillars, overload vs override, process vs thread, ACID, joins, TCP vs UDP, OSI
\end{itemize}

\section{6. 30-minute strategy}
\subsection{If coding}
\begin{enumerate}
  \item Minute 0--2: skim all problems; pick easiest first.
  \item Aim for \textbf{one fully correct} solution before polishing the second.
  \item Handle empty/single-element edge cases; print format carefully --- Cocubes is picky.
  \item Don't burn 25 min on an incomplete hard problem.
\end{enumerate}
\subsection{If aptitude / CF MCQs}
\begin{enumerate}
  \item $\sim$1 min per question budget; skip and return.
  \item Guess remaining at end if no negative marking.
  \item For CF: code-output / OOP conceptual questions are common eliminators.
\end{enumerate}

\section{7. Proctoring (unchanged)}
Expect webcam / AI flags (tab switch, second face, phone in frame). A 30-min test is still proctored --- integrity risk remains.

\section{8. Bottom line for \emph{your} invite}
\begin{itemize}
  \item \textbf{Duration:} 30 minutes total (confirmed by you).
  \item \textbf{Most probable CoCubes interpretation:} coding-only \textbf{or} aptitude-only (custom company config) --- \textbf{not} the full historical GE 3-part marathon.
  \item \textbf{Action:} check invite text for words like \textit{Coding}, \textit{Aptitude}, \textit{Technical}, \textit{Computer Fundamentals}. Prep both light coding + speed MCQs until the first screen confirms.
\end{itemize}
