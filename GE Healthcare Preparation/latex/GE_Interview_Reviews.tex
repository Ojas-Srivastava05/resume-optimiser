\section{Process map (SVNIT-style, 2024--2025)}
\begin{itemize}
  \item \textbf{5 rounds} reported by senior + EEDP FTE write-ups: OA $\rightarrow$ HireVue $\rightarrow$ Tech $\rightarrow$ HR $\rightarrow$ Personality. \tg{Confirmed}
  \item EEDP summer intern at SVNIT (Aug 2024): CGPA $>$ 7; CSE/ECE/Electrical eligible; 2-month internship.
  \item Stipend EID 2027 form: \textbf{INR 40,000/month}, 8 weeks; PPO pathway to EEDP + 6-month spring intern.
  \item Location: often \textbf{Bengaluru} (JFW Technology Centre) for software tracks.
\end{itemize}

\section{Interview tactics}
\begin{itemize}
  \item \textbf{Drive toward strengths:} mention Django auth, quiz logic, team leadership early.
  \item \textbf{Logic $>$ syntax:} narrate approach; ask clarifying questions.
  \item \textbf{OOP + DSA:} if asked to code Two Sum / tree sum, wrap in a class (EID 2024 pattern).
  \item \textbf{Stuck on design?} Think aloud; ask for hints --- senior's interviewer helped.
  \item \textbf{Don't assume live demo} --- but know URLs and 2-min demo script anyway.
  \item \textbf{Healthcare angle:} reliability, testing, clear documentation --- even without PHI data.
\end{itemize}
