\begin{verbatim}

FROM employee

\end{verbatim}

\noindent Then say, once: an inner join keeps matches. A left join keeps every left row and fills nulls on the right. A primary key identifies a row and is not null. A foreign key points at a primary key. An index speeds the lookup and slows the write. At IFFCO the slow query filtered or joined on one column, so the index is on that column. A full scan became a lookup. SQL is the query language. PL/pgSQL is PostgreSQL's language for functions with IF and loops. I write SQL. I have not shipped PL/pgSQL. A database is the catalog. A schema is a namespace inside it. My production engine is MySQL.

\section{8:05. Fundamentals, one example each}
\textbf{OOP, from the code, not from animals.} Encapsulation: SQL stays behind the function the route calls. Abstraction: the caller asks for corridors and does not see Redis. Inheritance: say you composed services unless you actually subclassed. Polymorphism: one handler shape, behaviour depends on the real type, if you have that. Overloading is the same name with different inputs, decided at compile time in Java. Overriding is a child replacing a parent method. An abstract class can hold state. An interface is a contract. In Python the closest thing you use is a base class.

\textbf{Hashing.} The key becomes a bucket. Average lookup is constant. The worst case is a long chain in one bucket. An array scan is linear. The map wins when you look up many times. An array wins when the data is tiny or you need order by index. Redis is the same idea: a key to a value, not a scan of every corridor.

\textbf{Trees, names only.} Inorder, preorder, postorder, and level order with a queue. Inorder on a BST is sorted. Level order is ``nearest.''

\textbf{AI versus ML.} AI is a system taking a decision a person used to take. ML is fitting a model on data. LogiFlow's delay model is ML. Gemini on Community Hero is a model I call, not a model I trained. A JWT check is neither.

\textbf{DBMS.} IFFCO stayed in MySQL because the workflows were tables, joins, and an index. Community Hero uses Firestore because a report is fetched by id or by a map cell. ACID if they ask: a transfer is atomic, leaves the books consistent, is isolated from the one beside it, and stays after a crash.

\textbf{Networks.} TCP is reliable and ordered. UDP is not. HTTP sits on TCP. AirHelp alerts go out on a WebSocket so a gate change does not wait for the next poll.

\textbf{OS, because it is on the coursework line.} A process has its own memory. Threads in one process share it. Deadlock needs mutual exclusion, hold and wait, no preemption, and a cycle. I would name which one a timeout breaks.

\subsection{Type these four. Say the idea, then the code, then the cost}
\textbf{1. Frequency.} One pass, a dict. $O(n)$ time, $O(n)$ space. Sorted output adds a sort.
\begin{verbatim}
def freq(nums):
    count = {}
    for x in nums:
        count[x] = count.get(x, 0) + 1
    return count
\end{verbatim}

\textbf{2. Compare two dates, dd/mm/yyyy.} Split, then compare year, month, day as a tuple. Reject 31/02 before comparing.
\begin{verbatim}
def later(a, b):
    da, ma, ya = map(int, a.split("/"))
    db, mb, yb = map(int, b.split("/"))
    return (ya, ma, da) > (yb, mb, db)
\end{verbatim}

\textbf{3. kth largest.} Min-heap of size k. The top of that heap is the answer. $O(n \log k)$.
\begin{verbatim}
import heapq
def kth_largest(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)
    for x in nums[k:]:
        if x > heap[0]:
            heapq.heapreplace(heap, x)
    return heap[0]
\end{verbatim}

\textbf{4. Binary search.} Window shrinks because the array is sorted. Check both ends and a missing target.
\begin{verbatim}
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
\end{verbatim}
