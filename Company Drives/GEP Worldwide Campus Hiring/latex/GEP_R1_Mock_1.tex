\section{Script}

\subsection*{0:00 --- Opening}
\IV{Good afternoon, Ojas. I have your resume. Tell me about yourself.}
\You{Locked intro. Stop.}

\subsection*{2:00 --- OOP block}
\IV{Explain the four pillars of OOP. Real-world examples --- not textbook definitions.}
\You{Encapsulation --- route service hides Redis; callers only see \texttt{getRoutes()}. Abstraction --- steering wheel, no rack detail. Inheritance --- Vehicle $\rightarrow$ Car/Truck. Polymorphism --- \texttt{cost()} differs for railway vs road route.}

\IV{Go deeper on polymorphism and inheritance. Where did you use both?}
\You{Three LogiFlow pipelines share output shape. Ranker calls same interface on railway, comparator, hybrid --- ranks time, cost, delay. Inheritance = reuse; polymorphism = one call, many behaviours.}

\IV{Compile-time or runtime polymorphism? One example each.}
\You{Overloading = compile-time --- same name, different params. Overriding = runtime --- subclass method through base reference. LogiFlow ranker on pipeline output is runtime.}

\IV{What is the purpose of OOP? Not ``reusability.''}
\You{Model system as objects owning data and behaviour. Change stays local --- swap railway pipeline without touching ranker. Reuse is a side effect.}

\subsection*{8:00 --- LogiFlow deep dive}
\IV{Walk me through LogiFlow. What problem and what was your role?}
\You{Ranks freight routes on time, cost, delay risk. Technical co-lead. 580+ corridors, 15k+ train-days. FastAPI, Next.js, Redis --- 100--400 ms. pytest 100/100 business rules.}

\IV{Draw the flow --- user query to ranked result.}
\You{Request $\rightarrow$ FastAPI $\rightarrow$ Redis check (cache-aside) $\rightarrow$ on miss: pipeline fetch/transform $\rightarrow$ ranker scores $\rightarrow$ cache + return $\rightarrow$ Next.js. SQL is source of truth.}

\IV{Why Redis? Stale cache? Redis down?}
\You{In-memory, sub-ms reads. TTL + invalidate on write. Redis down --- recompute from SQL; slower but correct. Cache never decides business truth.}

\IV{What difficulty did you face?}
\You{Latency. First version recomputed every request --- seconds. Cache-aside cut it to 100--400 ms.}

\subsection*{14:00 --- DSA}
\IV{Find the first non-repeating character. Talk before you write.}
\You{Two passes: count in hashmap, scan left-to-right for count 1. ``swiss'' $\rightarrow$ w. O(n) time, O(1) space fixed alphabet.}

\noindent{\small\textbf{Code sketch.} Pass 1 count; pass 2 return first with count 1. Empty string $\rightarrow$ sentinel.}
