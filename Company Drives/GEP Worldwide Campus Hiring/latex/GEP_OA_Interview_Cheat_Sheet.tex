\section{4) OS flash}
\begin{itemize}
  \item Process = program in execution. Thread = lightweight unit inside a process.
  \item \textbf{Deadlock (all 4):} mutual exclusion, hold \& wait, no preemption, circular wait.
  \item \textbf{Paging:} memory split into fixed pages / frames --- reduces external fragmentation.
  \item \textbf{Mutex:} one thread at a time. \textbf{Semaphore:} count-based access.
  \item Context switch = save / restore CPU state. Scheduling: preemptive vs non-preemptive.
\end{itemize}

\section{5) DBMS flash}
\begin{itemize}
  \item \textbf{PK} uniquely identifies a row. \textbf{FK} references a PK. Candidate key = minimal unique set.
  \item \textbf{1NF} atomic columns. \textbf{2NF} no partial dependency on PK. \textbf{3NF} no transitive dependency.
  \item \textbf{ACID:} Atomicity, Consistency, Isolation, Durability.
  \item \textbf{Index:} faster reads, slower writes. B-tree idea for ordered lookup.
  \item \textbf{INNER JOIN} = matching rows both sides. \textbf{LEFT JOIN} = all left rows + match or NULL.
  \item \textbf{GROUP BY + HAVING:} aggregate, then filter groups. WHERE cannot filter on aggregates.
\end{itemize}

\section{6) OOP ($<$2 min spoken)}
\begin{itemize}
  \item \textbf{Encapsulation} hide data. \textbf{Abstraction} what, not how. \textbf{Inheritance} reuse. \textbf{Polymorphism} same interface, different behavior.
  \item Access: public / private / protected.
  \item Stack = LIFO. Queue = FIFO. Linked list: O(1) insert at head, O(n) middle.
  \item BST: left $<$ root $<$ right. Graph: BFS = shortest unweighted path. DFS = explore / islands.
\end{itemize}

\section{7) Named algorithms --- 30s each}
\begin{itemize}
  \item \textbf{Kadane:} max subarray. Add to running sum; if sum $<$ 0, reset to 0; track max.
  \item \textbf{Binary search:} sorted array; lo / hi / mid; O(log n).
  \item \textbf{Two Sum:} hash map of complement; O(n).
  \item \textbf{BFS:} queue; level-order; shortest path on unweighted graph.
  \item \textbf{DFS:} stack / recursion; islands, connectivity.
  \item \textbf{Sliding window:} fixed or variable window on array / string.
  \item \textbf{Prefix sum:} precompute for range queries. \textbf{Dijkstra:} weighted shortest path (greedy + priority queue).
  \item \textbf{Sorting:} Merge O(n log n) stable extra space. Quick avg O(n log n) pivot matters. Heap O(n log n) in-place. Selection O(n$^2$) min swaps.
\end{itemize}

\begin{itemize}

  \item \textbf{SQL:} INNER JOIN authors a, books b ON a.id = b.author\_id. LEFT JOIN keeps authors with 0 books.
  \item \texttt{SELECT dept, COUNT(*) FROM emp GROUP BY dept HAVING COUNT(*) > 5}
\end{itemize}

\section{11) Coding interview loop --- never silent}
\begin{itemize}
  \item Clarify input / output + constraints $\to$ brute force (say complexity) $\to$ optimize (hash, two pointers, BS, Kadane)
  \item Code cleanly $\to$ dry-run 2 examples + edges (empty, one element, duplicates) $\to$ time / space
  \item If stuck: repeat the problem, start brute force, ask for a hint on approach. Partial credit beats silence.
\end{itemize}
